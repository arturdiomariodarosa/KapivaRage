# KapivaRage

Jogo de luta 2D no navegador, para jogar no computador ou no celular.

## Jogar

Abra: https://arturdiomariodarosa.github.io/KapivaRage/

- **Mover:** setas (ou o direcional na tela, estilo Super Nintendo)
- **Golpe:** J
- **Forte:** K
- **Defesa:** L
- **Magias:** → → ou ← → + GOLPE ou FORTE (cada personagem tem uma magia para frente e uma para trás; a lista aparece na seleção e na pausa)
- No celular, use o direcional à esquerda e os três botões à direita (GOLPE, FORTE, DEFESA). Toque e mouse funcionam.

A dificuldade começa em Fácil: o adversário anda e pula bastante, defende às vezes e ataca pouco.

## Rodar localmente

Não precisa instalar nada. Na pasta do projeto:

```bash
python3 -m http.server 8080
```

Depois abra http://127.0.0.1:8080/

Este repositório é uma cópia independente para o KapivaRage. O projeto original permanece em outro repositório, intocado.
